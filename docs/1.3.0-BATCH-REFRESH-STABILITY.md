## 1. Potwierdzona przyczyna zamykania ComboBox

Nieaktywna sesja Batch trafiała co tick do `RunAsync(() => services.Batch.RefreshQueueAsync(s), false)`. Mimo że to tylko obserwacja, `RunAsync` ustawiało `busy=true`, wykonywało `Render()`, a po zakończeniu przywracało `busy=false`, wykonywało drugi `Render()` oraz `LayoutPage()`.

`Render()` wywoływało `RefreshWorkflow()`. Jego `workflowMode.Enabled = !busy && !services.Batch.IsOperating` wyłączało pole podczas biernego odczytu. Framework prawidłowo usuwał fokus z niedostępnej kontrolki i zamykał jej popup. Ponowne włączenie pola nie przywracało użytkownikowi otwartego dropdownu.

**Dowód jest pomiarem rzeczywistego zdarzenia**, nie wyłącznie wnioskiem z kodu. Pierwszy trace `before-aborted/batch-ui-trace.jsonl` pokazuje:

| Sekwencja | Czas od inicjalizacji trace | Zdarzenie / stan |
|---:|---:|---|
| 317 | 22093,448 ms | `workflowMode.DropDownOpened`; Enabled=true, Focused=true, DroppedDown=true |
| 318 | 23830,85 ms | `tick`, jeszcze busy=false |
| 319 | 23830,86 ms | `RunAsync.observe.begin`, busy=true |
| 320–321 | 23830,86–23834,24 ms | `Render.begin` → `RefreshWorkflow.begin` |
| 322 | 23835,32 ms | `workflowMode.LostFocus`, Enabled=false |
| 323 | 23838,264 ms | `workflowMode.DropDownClosed`, busy=true, scope=`RefreshWorkflow` |
| 324 | 23838,42 ms | `workflowMode.EnabledChanged`, Enabled=false |
| 327–330 | 23841,33–23849,40 ms | zakończenie obserwacji i ponowne Enabled=true, popup pozostaje zamknięty |

Zamknięcie nastąpiło **1744,816 ms po otwarciu**. Kontrolka zachowała identity=4, parent=9, bounds 207×34 oraz SelectedIndex=0. Nie było wymiany instancji, reparentingu ani zmiany rozmiaru w tej sekwencji. Samo `EnabledChanged` jest emitowane po obsłużeniu skutków zmiany właściwości, dlatego zdarzenie DropDownClosed pojawia się w logu wcześniej.

Zarejestrowany stos metod, zapisany bez argumentów i ścieżek:

```text
BatchImportView.RunAsync → Render → RefreshWorkflow
  → Control.set_Enabled → RetireUnavailableFocus
  → ControlFocusScope.Retire / Request → NotifyFocusLost
  → ComboBox.OnDeselected → set_DroppedDown → OnDropDownClosed
```

To błąd użycia ścieżki akcji użytkownika do biernej obserwacji w aplikacji. Ten dowód nie wskazuje konieczności zmiany ModernFormsNext. Nie należy go również utożsamiać z wcześniejszym, niezależnym FAIL QualityDropdown w 17. cyklu.

## 4. Ograniczona diagnostyka i reprodukowalna analiza

`BatchImportView.Diagnostics.cs` jest włączane wyłącznie w Debug przez `MTD_QA_BATCH_TRACE`. Wymaga nowego absolutnego pliku bezpośrednio pod jawnym `MODERNTUBEDOWNLOADER_DATA_ROOT`, nie dopisuje do istniejących dowodów, odrzuca reparse ancestors. Release nie wykonuje hooków. Snapshoty zawierają liczby i stany, bez tekstu listy, URL-i, tytułów, cookies lub prywatnych ścieżek; stosy zawierają wyłącznie nazwy metod. Serializacja i zapis JSONL odbywają się poza wątkiem UI, lecz pobieranie snapshotów i stosów ma niezerowy koszt na UI.

Limit to 4096 rekordów. `trace.limit` oznacza koniec szczegółowej osi zdarzeń; zarezerwowany rekord `dispose` może nadal zachować końcowe liczniki. Nie wystarczy do odtworzenia kolejności zdarzeń poza limitem. Brak finalnego dispose jest jawnie oznaczany. To diagnostyka jednej instancji widoku i nowego pliku; kolejny proces nie powinien używać tego samego istniejącego pliku.

Analiza bez uruchamiania aplikacji:

```powershell
& ./artifacts/batch-flicker-20261115/Measure-BatchTrace.ps1 `
  -TracePath ./artifacts/batch-flicker-20261115/before-full/batch-ui-trace.jsonl `
  -OutputPath ./artifacts/batch-flicker-20261115/before-full/trace-metrics-new.json
```

Skrypt zachowuje stare wyniki przez odmowę nadpisania. Wylicza różnice liczników w oknach otwartego dropdownu, pokrycie okna, czasy zakończonych scope, wystąpienie limitu i finalnego podsumowania. Zamknięcie po jawnej akcji Collapse trzeba odróżnić od błędu na podstawie stosu, scope i natywnych świadków; samo wystąpienie DropDownClosed nie oznacza FAIL.

## 5. Zaimplementowane poprawki i zakres walidacji

- **P0 zaimplementowane:** bierne RunAsync zastąpiono obserwacją rzeczywistych zmian.
