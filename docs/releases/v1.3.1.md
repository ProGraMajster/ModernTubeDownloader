# ModernTubeDownloader 1.3.1

## New

- File Organizer identifies the source, destination or affected list when a path fails validation. Local diagnostics include the operation, reason and Windows error code.

## Improvements

- Use a local drive root as the source for a top-level scan by turning off subfolder scanning. Suggested list folders can be created below a local drive root.
- If a suggested folder is unavailable, enter another destination for that list and analyze again. Error text is available in all 16 app languages.

## Fixes

- The Organizer preserves the original Unicode spelling of existing Windows directories and correctly cleans mixed trailing spaces and dots from generated list names.
- The same History, queue, settings and Organizer journal formats carry over from 1.3.0. Existing move confirmation, no-overwrite behavior and journal recovery still apply.

## Known Issues

- Choose a folder below the drive root for the destination. Network shares, device paths, system directories, symlinks and junctions are outside the Organizer's supported paths.
- See the [1.3.0 known issues](v1.3.0.md#known-issues) for product limitations.
