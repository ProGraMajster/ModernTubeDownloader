# ModernTubeDownloader 1.1.0

Download the Windows x64 ZIP, extract it and run ModernTubeDownloader.exe. The self-contained runtime needs no separate .NET installation; yt-dlp, FFmpeg and Deno are installed automatically on first start. Check the accompanying SHA-256. Separate symbols are for diagnostics, not required to run.

## What's new

### Browser extension

- Polish/English UI, immediate language switching and a full Options/reset page.
- Generic supported-URL Analyze/QuickQueue handoff; desktop yt-dlp checks actual support.
- Preserved YouTube watch/Shorts/playlist/LIVE/replay integration. Click opens a modal; only confirmation sends the request. Completed LIVE replays enter VOD; active/upcoming recordings still require desktop confirmation.
- Safe cleanup after extension reload; older pre-guard YouTube tabs need one normal reload. No page-reload loop. The extension remains unpacked, not published to a browser store.

### Web Remote

- Follow app / PL / EN, one-time short pairing codes and HttpOnly sessions.
- Optional explicitly configured HTTPS and clearer mobile time-range input.
- Idle updates preserve unchanged UI and editing state. Use a trusted LAN; HTTP is not encrypted.

### System notifications

- Optional Downloads/LIVE notifications with progress, cached thumbnails, privacy mode and safe actions.
- Local WebP-to-PNG normalization and capability-driven Windows provider fallback.
- Availability/display/actions depend on Windows, installed runtime and notification policy.

### Authentication

- **Optional, opt-in** browser-cookie synchronization: you choose domains/cookies and explicitly grant permissions. No automatic collection of all cookies.
- Standalone Native Messaging host, Windows DPAPI-encrypted profiles and canonical yt-dlp cookie-file integration. Manual cookies.txt remains supported; auth sources are exclusive.
- With before-use consent, auth failure requests a correlated fresh snapshot and permits exactly one retry using a new jar. Offline/denied/timeout/second failure requires manual Sync/Retry.
- Register the exact extension ID in desktop Settings from the normally launched app. Repair registration after moving the installation.
- Delete old profiles from extension Settings without confusing them with active scopes. Active-profile deletion waits for native confirmation; failed/pending deletions remain visible.

### Reliability

- Latest fetched ModernFormsNext master, consistent development/CI/release pin.
- Sequential full Debug/Release tests and package gates; separate NativeHost/runtime, symbols and redistribution notices.
- Existing resume/recovery and independent LIVE preserved; auth reconnect retries only after preserving the failed part.
- Fixed inherited thumbnail-file handle race and hardened expert arguments against credential/execution ownership bypass.

## Security / privacy

Cookie sync is off by default. Credentials use Native Messaging and per-user encrypted storage, never Web Remote, media URI, clipboard or extension storage. UI/status/logs do not display cookie values. Partitioned cookies are excluded, not flattened. A temporary private Netscape jar is necessary for yt-dlp; this is not protection against malware running as the same Windows user. Real account/session validity remains source/account dependent.

## Known limitations

- SponsorBlock Remove is **Experimental/default OFF**, with confirmed edit-point playback defects; prefer Mark/MKV or OFF.
- LIVE FromStart is **Experimental/source-dependent**; scheduled monitoring needs the app running.
- Extractor availability does not certify every URL/account/feature; no DRM bypass.
- Edge/Brave/Chromium, exhaustive DPI/device/clean-PC/soak and all Windows notification capabilities are not fully qualified.
- Native registration must be repaired after an installation move. This portable release is not a packaged/MSIX deployment claim and is not code-signed.
- See README, COOKIE_SYNC.md, SYSTEM_NOTIFICATIONS.md and THIRD_PARTY_NOTICES.md in the ZIP for setup, limits and licenses.
