# ModernTubeDownloader 1.3.1

## Nowe

- Organizator plików wskazuje źródło, cel lub listę, której dotyczy błąd ścieżki. Lokalny log zapisuje operację, przyczynę i kod błędu Windows.

## Ulepszenia

- Katalog główny dysku lokalnego można przeszukiwać po wyłączeniu skanowania podfolderów. Organizator może proponować foldery list bezpośrednio pod katalogiem głównym.
- Jeśli zaproponowany folder jest niedostępny, można wpisać inny folder docelowy i ponowić analizę. Komunikaty są dostępne we wszystkich 16 językach aplikacji.

## Naprawy

- Organizator zachowuje oryginalny zapis Unicode istniejących folderów Windows oraz poprawnie usuwa końcowe spacje i kropki z generowanych nazw.
- Ustawienia, Historia, kolejka i dziennik Organizatora zachowują formaty z 1.3.0. Nadal obowiązuje potwierdzenie przeniesienia, ochrona przed nadpisaniem i odzyskiwanie z dziennika.

## Znane ograniczenia

- Folder docelowy musi znajdować się poniżej katalogu głównego dysku. Organizator wyklucza udziały sieciowe, ścieżki urządzeń, katalogi systemowe, dowiązania symboliczne i punkty połączeń.
- Pozostałe ograniczenia opisują [informacje o wydaniu 1.3.0](v1.3.0.md#known-issues).
