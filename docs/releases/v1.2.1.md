# ModernTubeDownloader 1.2.1

This patch focuses on reliability and large Batch Import workloads. It retains the Classic UI.

## Storage safety

- Stop new VOD admissions when the target folder/drive becomes unavailable.
- Pause safely after disk-full or queue-persistence failures; require a writable probe
  and successful current checkpoint before explicit Resume.
- Preserve partial/recovery VOD and LIVE files on storage failure.

## Batch Import

- Move heavy import and queue handoff off the UI context; coalesce progress and persistence.
- Render at most 50 download cards per page rather than rebuilding thousands of controls.
- Reconcile large batches faster, including missing/interrupted jobs; respect filtered selection.
- Improve cancellation and bounded streaming JSON handling with localized errors/examples.
- Default new analysis sessions to one worker. Download concurrency remains one by default;
  explicitly saved preferences are preserved.
- Separate preparation/download progress and show advisory size/transfer ETA when sufficient
  metadata exists. Unknown values are indicated; estimates do not guarantee peak disk use.

## Notifications

- Use pinned ModernFormsNext `8d8a7679779608b4edbee7dc687c13e3b1a611d9` for provider fallback
  resilience and bounded Shell identity lifetime. Backend failures remain isolated from media work.

## Installation

Download `ModernTubeDownloader-1.2.1-win-x64.zip`, verify its matching SHA-256, extract and run
`ModernTubeDownloader.exe`. Windows x64, self-contained .NET, multi-file and untrimmed.
Media tools are provisioned separately on first start. Symbols are a separate optional ZIP.

## Notes

- HTTP 403/500 and source availability errors can still originate from providers/yt-dlp.
- SponsorBlock Remove remains Experimental/default OFF with known playback defects.
- LIVE FromStart remains Experimental/source-dependent; MFN #204/#205 typography limits remain.
- Physical Windows 11 23H2, exhaustive device/DPI/soak and clean-PC updater qualification are
  not claimed. Binaries are not code-signed; SHA-256 is an integrity check, not a signature.
- No Modern Dashboard branch changes, retry/auth policy changes, browser-store or NuGet release.
