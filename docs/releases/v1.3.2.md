# ModernTubeDownloader 1.3.2

This stable hotfix improves File Organizer recovery, separates the application updater from its installer, and adds local diagnostic tools in both desktop interfaces.

## New

### Advanced Diagnostics

- Open **Settings → Diagnostics** in Modern Dashboard or Classic. Enable DEBUG or TRACE at runtime and retain the choice across restarts. Standard logging remains available with advanced logging disabled.
- Browse or clean up local logs, copy a technical summary, and export a diagnostic ZIP for a recent period or all available dates. Export is cancellable and saves only to the location you select.
- The ZIP contains filtered structured events, app and assembly versions, system and storage information, and a limited settings summary. Legacy text logs are excluded. The app does not upload the ZIP.
- To report a problem, enable diagnostics, reproduce the issue, export a ZIP, review it, and attach it to your report with the approximate time, the action you took and the result you saw. Avoid attaching raw profiles or unfiltered logs.

## Improvements

### File Organizer

- Preview rechecks drive availability and retries a suggested destination when an unavailable volume becomes accessible. You can retry in the same window.
- The preview shows validation, import, scan, matching and preparation stages. It supports cancellation and clears stale rows before starting another analysis.
- Local scan and metadata work is reused within an analysis. Results retain bounded paging. Preview leaves the library in place, and move and undo retain their existing safety checks.

### Performance and Stability

- Structured logging uses bounded queues, batched writes, rotation and retention. It prioritizes warnings and errors and reports entries dropped under load.
- Advanced diagnostics periodically samples process CPU, memory, garbage collection and collection sizes. Organizer, History and Queue report relevant work and presentation timings.
- Batch-session diagnostics distinguish missing metadata, unsupported schemas, invalid IDs and phases, and read failures. Existing recovery safeguards continue to protect incomplete sessions.

### Localization

- Updated all 16 interface catalogs for Diagnostics, Organizer progress and cancellation, and installer recovery and restart outcomes.
- Updated the bundled What's New summary in English and Polish. English remains the fallback for other languages.

## Fixes

### Application Updates

- The GUI loads the update protocol independently of the external installer DLL. The installer continues to run from its own directory.
- The install-on-exit checkbox now preserves the selected value when the panel refreshes.
- The app shows an installer outcome even when the staged ZIP is missing. A shared operation ID ties together the GUI request, installer events and result consumption after launch.

### Update Reliability and Recovery

- The installer writes and verifies backups before applying files and records each write before changing the destination. It replaces the transaction journal at completion.
- Rollback verifies the SHA-256 of original files, preserves incomplete or unverifiable recovery evidence, and reports verified, partial or unknown recovery.
- Journal and result replacement use bounded retries for sharing or lock violations. Access denied remains visible. A failed restart or immediate process exit is distinct from an installation failure.
- The installer continues to check the package SHA-256, validate paths and wait for the parent process to exit before writing.

## Known Issues

- Updates started by 1.3.0 or 1.3.1 still run that version's installer first. A journal access error can interrupt an in-place upgrade. Some 1.3.1 installations with an updater DLL binding error cannot start the update service. [Journal access issue](https://github.com/ProGraMajster/ModernTubeDownloader/issues/23) · [Updater assembly issue](https://github.com/ProGraMajster/ModernTubeDownloader/issues/29)
- The stable release and the in-app updater use the same GitHub Releases channel. The release cannot selectively disable automatic installation for affected older clients.
- Qualification used isolated profiles and drives on Windows 11 build 26300. The affected user's machine and Windows 11 build 22631 were unavailable for this qualification.

### Manual Upgrade Instructions

1. Close ModernTubeDownloader completely, including any tray instance, and wait for any installer process to finish.
2. Back up the existing profile. The default location is `%LOCALAPPDATA%\ModernTubeDownloader`. If you use `MODERNTUBEDOWNLOADER_DATA_ROOT`, back up that directory instead. Preserve the original installation and its recovery journal if recovery was partial or unknown.
3. Download the complete `ModernTubeDownloader-1.3.2-win-x64.zip` and matching `.sha256` file from the official release. Compare the ZIP's SHA-256 with the published value. On Windows you can use `Get-FileHash -Algorithm SHA256 .\ModernTubeDownloader-1.3.2-win-x64.zip`.
4. Extract the complete archive into a **new writable folder**. Avoid copying individual DLLs into an existing installation.
5. Start the new `ModernTubeDownloader.exe` with the same Windows account and existing profile configuration. Verify your settings and open **Settings → Updates**. Repoint your shortcuts after confirming the new installation works.
