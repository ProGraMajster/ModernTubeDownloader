# ModernTubeDownloader 1.3.2

## New

- Local update diagnostics record the external installer version and installation stages.

## Improvements

- File Organizer shows which part of the analysis is running and supports cancellation during the dry run.

## Fixes

- The update service runs independently of the external installer assembly.
- File Organizer can retry a suggested destination after the drive returns. It reports success, an error or cancellation after every analysis.

## Known Issues

- If updating from 1.3.1 fails in Settings, extract the verified 1.3.2 ZIP into a new folder and keep the existing application profile.
