# ModernTubeDownloader 1.2.0

Windows x64 self-contained ZIP: extract to a writable folder and run
`ModernTubeDownloader.exe`. No separate .NET install or manual media-tool setup is
needed. yt-dlp, FFmpeg/ffprobe and Deno are provisioned on first start, not bundled.

## What's new

### Automatic updates

- Stable GitHub Release checks, manual/daily/weekly settings and original release notes.
- SHA-256-verified staging; separate updater waits for graceful application exit.
- Install now or on exit, per-file backup and rollback; user data stays untouched.
- Application updates are independent of ToolManager updates. SHA-256 checks integrity,
  not an independent publisher signature; this release is not code-signed.

### System tray & startup

- Minimize/close-to-tray, same-instance restore, queue pause/resume and LIVE navigation.
- Work-aware exit confirmation; hiding is not shutdown.
- Optional current-user Windows startup and hidden start, explicit registration repair.

### Other / Batch import

- A working Other tools page with Batch launcher and recent preparation sessions.
- TXT, quoted CSV and JSON imports with streaming bounds, limited metadata workers,
  statuses, filtering, paging and durable sessions for large datasets.
- Explicit selection/queue handoff reuses the canonical queue/auth/source services;
  it does not automatically start LIVE recordings or create a second downloader.

### Personalization

- Live 80–200% application text size, independent of Windows DPI.
- Light/Dark/System/Custom, semantic accent/colors, density/spacing, per-page options.
- Default/Compact/Large/Minimal presets and validated JSON import/export/reset.
- Settings organized into eleven categories without changing queue/LIVE ownership.

## Known limitations

- Application-owned text scales, but some implicit MFN composite-control text does not
  fully follow it: tab headers may stay default-sized ([#204](https://github.com/ProGraMajster/ModernFormsNext/issues/204));
  embedded NumericUpDown editor digits may stay default-sized ([#205](https://github.com/ProGraMajster/ModernFormsNext/issues/205)).
  Accepted post-1.2 follow-up, no reflection/copied controls/DPI workaround. After the
  upstream fixes, update the pin and qualify a likely 1.2.1.
- Polski: niektóre etykiety kart i edytory liczb nie podążają w pełni za globalnym
  skalowaniem tekstu. #204/#205 są zaakceptowanymi ograniczeniami; nie blokują 1.2.0.
- SponsorBlock Remove remains Experimental/default OFF with confirmed edit-point
  playback defects. Prefer Mark with MKV or leave it off.
- LIVE FromStart remains Experimental and source-dependent; recovery saves separate
  verified parts rather than unsafe concatenation.
- Exhaustive DPI/scale/page/theme/resize, actual login/tray soak, clean-PC updater,
  20 distinct real Batch sources, native pickers and physical-device matrices remain
  post-release QA. Partial/unexecuted checks are not presented as PASS.
- Portable moves may require explicit protocol, Native Messaging and startup repair.
  Account-session/source support depends on yt-dlp; cookies are opt-in and scoped.
