## ModernTubeDownloader 1.0.0

The first public Windows x64 release: a native yt-dlp frontend with persistent downloads and independent LIVE recording.

### Highlights

- VOD analysis, quality selection, playlists and a persistent bounded-concurrency queue.
- Independent LIVE FromNow, Stop and save, scheduled monitoring, reconnect and verified partial/recovery parts.
- Matching-format VOD resume, bounded transient retries and optional pacing.
- Supported-services runtime catalog, search and metadata-only URL checks.
- Chrome/Edge YouTube extension source and an opt-in authenticated LAN Web Remote with mobile-friendly range input.
- Subtitles, time ranges, Auto/MP4/MKV/WebM and FFmpeg stream-copy merge/remux.
- History, full JSON sidecars and publication-date timestamps.
- Polish/English, Light/Dark/System and automatic media-tool installation/update checks.

### Install

Download **ModernTubeDownloader-1.0.0-win-x64.zip**, verify its SHA-256, extract and run **ModernTubeDownloader.exe**. .NET is included. First start downloads and validates yt-dlp, the GPL-configured FFmpeg/ffprobe build and Deno; those tools are not bundled.

The symbols ZIP is optional for diagnostics. The extension is repository/source content, not a Chrome Web Store publication. This first release is unsigned; Windows may show an unknown-publisher/SmartScreen warning.

### Known limitations

- **SponsorBlock Remove is Experimental/default OFF:** frozen video and other edit-point playback defects are confirmed. No stable-quality guarantee or transcoding workaround. Mark with explicit MKV is supported.
- **FromStart is Experimental/source-dependent.** Upcoming monitoring requires the running app; retained source fragments govern recovery.
- An available extractor does not mean every source/account/URL/feature is MTD-verified.
- **Cookies.txt is optional and user-supplied.** No browser-cookie extraction; restricted media depends on authorized credentials and source behavior.
- Stream-copy ranges can be keyframe-aligned; ranges cannot combine with subtitles/SponsorBlock and Remove cannot combine with subtitles.
- Unknown terminated VOD tools can require explicit Retry. Exhaustive device/DPI/browser/source and long-soak QA remain post-1.0 follow-up.
