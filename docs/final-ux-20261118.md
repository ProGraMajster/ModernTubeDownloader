## Installed-version release notes and Help

`Resources/ReleaseNotes.json` is a reviewed embedded manifest with `schemaVersion: 1`, exact version records, localized section titles and plain-text items. The four required categories are `new`, `improved`, `fixed` and `limitations`. Parsing limits include 256 KiB, depth 16, at most 20 version records, at most 12 items per section and 4096 characters per item. Missing/duplicate/invalid categories or versions are rejected.

Only `1.3.0-candidate.1` currently has bundled notes. Other versions cannot borrow that record, including stable `1.3.0`, another candidate or an available update. Build metadata is normalized away; version-bound official links reject URL/path/query/fragment input. The candidate is identified as a candidate, with known limitations and no invented publication date or qualification claim. There is no fake older-version selector when no older records exist.

PL and EN content is reviewed locally. Other locales show explicit EN fallback instead of pretending that release-note prose was translated. Notes render immediately from the application resource. The optional online action opens the exact official repository release-tag link in the browser; the application does not fetch remote Markdown/HTML, execute scripts, substitute another tag or replace bundled content. A missing candidate release, network failure, rate limit or browser HTTP 404 therefore cannot erase or delay the offline content. This architecture is not presented as an executed live HTTP-response test.

The existing experience service still controls Later/acknowledgement and persistence. Merely opening notes or opening the optional release link does not acknowledge another version. Explicit acknowledgement is saved only after a real user action; missing exact local notes do not acknowledge borrowed content. The existing updater and migration runtime were not replaced.

Help uses six local topic sections: getting started; downloads/playlists and History; LIVE; Batch and Organizer; Settings and updates; diagnostics/documentation. Actions route through existing application navigation and tools. Content uses PL/EN with explicit EN fallback; controls retain localized existing action labels. Cards wrap/scroll with text scale instead of using fixed-height paragraphs. [Before Help](../artifacts/final-ux-20261118/before-debug-directed/help.png) and [corrected Help](../artifacts/final-ux-20261118/after-debug-dark-pl/help.png) are retained.

The earlier expanded targeted run passed **17 ReleaseNotesCatalogTests, 32 ExperiencePresentationTests and 58 UserExperienceServiceTests**.
